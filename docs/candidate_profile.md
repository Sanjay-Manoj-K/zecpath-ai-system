# Candidate Profile

## Purpose

This document defines the standard structure used to represent candidate information extracted from resumes. The profile provides a consistent format for storing personal, educational, professional, and additional information, regardless of the original resume layout.

## Candidate Profile Structure

### Personal Information
- Full Name
- Email Address
- Phone Number
- Location
- LinkedIn Profile (Optional)
- GitHub / Portfolio (Optional)

### Professional Information
- Professional Summary / Objective
- Current Designation
- Total Years of Experience
- Technical Skills
- Soft Skills
- Work Experience

### Education
- Degree
- Institution
- Graduation Year
- CGPA / Percentage (Optional)

### Projects
- Project Title
- Description
- Technologies Used
- Role

### Certifications
- Certification Name
- Issuing Organization
- Completion Year

### Languages
- Languages Known

### Achievements
- Awards
- Publications (Optional)
- Extra-Curricular Activities (Optional)
