# Job Profile

## Purpose

This document defines the standard structure used to represent job requirements extracted from job descriptions. It provides a consistent format for storing job-related information, enabling accurate matching between candidates and job opportunities.

## Job Profile Structure

### Basic Information
- Job Title
- Company Name
- Department
- Job Location
- Employment Type
- Work Mode (Remote / Hybrid / On-site)

### Job Requirements
- Required Skills
- Preferred Skills
- Minimum Experience
- Maximum Experience
- Education Requirements
- Certifications (Optional)

### Responsibilities
- Key Responsibilities
- Daily Tasks

### Additional Information
- Salary Range (Optional)
- Benefits (Optional)
- Application Deadline (Optional)
