# Skill Object

## Purpose

This document defines the standard structure used to represent an individual skill extracted from resumes and job descriptions. It ensures that skills are stored in a consistent format for accurate comparison and AI-based matching.

## Skill Object Structure

### Skill Information
- Skill Name
- Skill Category
  - Programming Language
  - Framework
  - Database
  - Cloud
  - Tool
  - Soft Skill
- Proficiency Level
  - Beginner
  - Intermediate
  - Advanced
  - Expert
- Years of Experience
- Last Used (Optional)
- Mandatory / Optional
