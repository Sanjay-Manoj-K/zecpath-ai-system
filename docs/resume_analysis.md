# Overall Analysis

After analyzing resumes from multiple domains, several common patterns were identified:

- Most resumes contain Personal Information, Professional Summary or Objective, Skills, Work Experience, and Education.
- Technical resumes emphasize programming languages, tools, projects, and certifications.
- Non-technical resumes emphasize achievements, responsibilities, and relevant experience.
- LinkedIn profiles are more common than GitHub or portfolio links.
- Section titles vary across resumes (e.g., Work History, Professional Experience, Relevant Experience), but the underlying information remains similar.
- Resume layouts differ, but the core candidate information is largely consistent.

These observations will be used to design a standardized Candidate Profile data model and Resume JSON schema for the AI hiring system.
