# Experience Object

## Purpose

This document defines the standard structure used to represent a candidate's work experience extracted from resumes. It provides a consistent format for storing employment history, making it easier for the AI system to compare candidate experience with job requirements.

## Experience Object Structure

### Experience Information
- Company Name
- Job Title
- Employment Type
  - Full-time
  - Part-time
  - Internship
  - Contract
  - Freelance
- Start Date
- End Date
- Duration
- Responsibilities
- Technologies Used (Optional)
- Achievements (Optional)
