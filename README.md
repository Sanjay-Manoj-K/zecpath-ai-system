# Zecpath AI System

## Overview
Zecpath AI System is an AI-powered recruitment platform that automates resume screening, AI interviews, candidate evaluation, and hiring workflows.

## Project Structure

- data/ - Sample data and resumes
- docs/ - Architecture and documentation
- parsers/ - Resume and job description parsers
- ats_engine/ - ATS scoring and ranking
- screening_ai/ - AI screening modules
- interview_ai/ - AI interview modules
- scoring/ - Candidate scoring and recommendations
- utils/ - Utility functions
- tests/ - Unit tests

## Installation

```bash
python -m venv .venv
pip install -r requirements.txt
```
